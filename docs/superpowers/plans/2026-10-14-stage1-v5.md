## Review Focus

1. A latent block followed by empty/adjacent text must preserve the original-step denominator and exclude only crossing auxiliary tokens — Tasks1/2.
2. A rank with zero eligible targets during a partial accumulation must participate in the same collectives and preserve distinct denominators — Task5.
3. A resumed student whose weights differ from initialization must restore the immutable initial reference before helper or reference execution — Task4/5.
4. F and packed recomputation must use optimizer-owned sparse rows and the same source-coordinate dropout while retaining prefix gradients — Task3/5.
5. Prefix/suffix maxima from different blocks can jointly dominate packed memory; managed worktree roots and sourced defaults must resolve identically on both nodes — Task6/7 and execution gates.
