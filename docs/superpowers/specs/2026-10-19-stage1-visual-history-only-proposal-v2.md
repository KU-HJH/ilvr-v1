## Exact data flow
Keep baseline global intent u, helper visual encoding, grouping (helper_group_L256), candidate ownership/order and cosine/softmax selector unchanged. Keep baseline current text positions and their native-dtype mean t_i, including its first-block assistant header behavior. No discounted text accumulation and no gamma control.

Replace baseline mean of the most recent nonempty block's selected raw visual targets with b_i over all previously selected raw visual targets Z_<i of this sample. Use current segment's baseline text hidden rows H_i to compute the same external metric: w[p] = mean_t softmax_p(cos(H_i[t], Z_<i[p])), temperature1, FP32, no gradients; b_i = sum_p w[p]*Z_<i[p]. All past target rows have equal prior and no temporal decay. The first-block header cannot enter this metric because there is no visual history yet. The baseline segment/filter semantics remain unchanged thereafter.

If current text or prior targets are empty, omit b_i, matching the metric's existing absent-history rule. Preserve baseline final query averaging/dtype: append b_i converted to the existing baseline hidden dtype to the unchanged u/t_i list, then use its existing stack/mean. With no history the query must equal historical baseline exactly. Select raw current helper candidates, not averaged history values, using the original cumulative probability0.9 and at most8 slots, stable tie order and first-K target packing. History contains this modified builder's own earlier selections, so subsequent changes in selections are intended downstream effects. Per-sample history resets at every build. This one visual-history component change jointly changes memory extent, relevance weighting and absent-text behavior; it does not isolate their individual contributions. Targets remain detached teacher-forcing/alignment values.

## Alternatives and selected route
1. Recommended: minimal experiment patch on pinned baseline source. This keeps the historical execution path and offers the strongest source-level isolation.
2. Add a generic new mode on current main standard training. More parser/checkpoint/resume integration and broader source differences require additional equivalence work.
3. Disable auxiliary terms and gamma on current v5. Rejected for this experiment: it retains v5 trainer/backend/batch restrictions and different first-block text filtering.
